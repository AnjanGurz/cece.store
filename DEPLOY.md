# CeCe Store — Cloud Backend Deployment Guide

## Architecture Overview

```
Netlify (frontend)          Render.com (backend API)
┌─────────────────┐         ┌──────────────────────────┐
│  index.html     │ ──────▶ │  backend/server.js        │
│  js/data.js     │  fetch  │  /api/products  (CRUD)    │
│  admin/admin.js │◀──────  │  /api/settings            │
│  catalog/       │  JSON   │  /api/analytics           │
└─────────────────┘         │  /api/auth                │
                            │  data/products.json       │
                            └──────────────────────────┘
```

**Without a Render URL configured:** The storefront uses `catalog/products.json` + localStorage — fully static, no backend needed.

**With Render URL configured:** Products, settings, and analytics are served live from the API. The admin dashboard can push changes to the cloud in real time.

---

## Step 1 — Push code to GitHub

```bash
git add .
git commit -m "Add cloud backend"
git push origin main
```

---

## Step 2 — Deploy to Render

1. Go to **https://render.com** and sign in
2. Click **New → Web Service**
3. Connect your GitHub repository
4. Render will auto-detect `render.yaml` — click **Apply**
5. On the service settings page, fill in **Environment Variables**:

| Key | Value |
|-----|-------|
| `ADMIN_PASSWORD` | Your secret admin password (pick a strong one) |
| `ALLOWED_ORIGINS` | Your Netlify URL, e.g. `https://cece-store.netlify.app` |

> `JWT_SECRET` is auto-generated by Render — no action needed.

6. Click **Deploy** — wait ~2 minutes for the first build
7. Copy your service URL, e.g. `https://cece-store-api.onrender.com`

---

## Step 3 — Configure the frontend

Open `index.html` and update line with `window.CECE_API_URL`:

```html
<!-- Before (local only) -->
<script>window.CECE_API_URL = '';</script>

<!-- After (cloud connected) -->
<script>window.CECE_API_URL = 'https://cece-store-api.onrender.com';</script>
```

Commit and push — Netlify redeploys automatically.

---

## Step 4 — Seed products (first deploy only)

The backend ships with 4 starter products in `backend/data/products.json`. To replace these with your real catalog:

**Option A — Bulk import via admin dashboard:**
1. Open your storefront, click the CeCe logo 5× to open admin
2. Log in with your `ADMIN_PASSWORD`
3. Go to **Cloud → Bulk Import / Export** 
4. Click **Export Products JSON** to download your current products
5. Click **Import Products JSON** and upload your file — it syncs to the cloud automatically

**Option B — Edit directly:**
Edit `backend/data/products.json` and redeploy.

---

## Step 5 — Verify everything works

1. Visit your Netlify URL — products should load from the Render API
2. Open DevTools → Network — confirm requests to `cece-store-api.onrender.com`
3. Open admin dashboard → **Cloud** tab → click **Test Connection** → should show "Cloud server is reachable."
4. Log in → cloud dot in sidebar turns green

## Local Development

```bash
# Install backend dependencies
cd backend
npm install

# Create .env from example
cp .env.example .env
# Edit .env → set JWT_SECRET, ADMIN_PASSWORD, ALLOWED_ORIGINS=*

# Start backend
npm run dev   # uses nodemon for auto-restart

# Open frontend
# Just open index.html in a browser (or use Live Server in VS Code)
# Set window.CECE_API_URL = 'http://localhost:10000' in index.html for local API
```

---

## Environment Variables Reference

| Variable | Required | Description |
|----------|----------|-------------|
| `JWT_SECRET` | Yes | Random string ≥32 chars for signing JWT tokens |
| `ADMIN_PASSWORD` | Yes | Password for admin login (stored as bcrypt hash) |
| `PORT` | No | Port to listen on (default: 10000) |
| `ALLOWED_ORIGINS` | No | Comma-separated CORS origins (default: allow all) |

## Free Tier Notes (Render)

- Free instances **spin down** after 15 minutes of inactivity
- First request after spin-down takes ~30 seconds to wake up
- The storefront falls back to localStorage cache during wake-up — no blank screen for customers
- Upgrade to Starter ($7/mo) to keep the server always-on
